# 极限刹车挑战 · 网页版

一个踩刹车的网页小游戏：车辆自动全力加速，到 **100 km/h** 后才能踩刹车；一踩下动力立即切断，
**按得越久、力度越大**，力度达到 **1612 N** 刹车踏板会被踩断，整车翻滚失败。
得分 = 刹车初速度² ÷ 刹停用时，越高越好。

- 纯静态页面（HTML + CSS + JavaScript + three.js），打开即玩，手机和电脑都行
- 按住屏幕任意位置、右下角按钮或空格键踩刹车，松手力度回落
- 排行榜存在浏览器本地（localStorage），不上传任何数据
- 附成绩曲线图，可以看到整段制动过程的踏板力度与车速
